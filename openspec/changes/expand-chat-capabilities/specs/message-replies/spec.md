## ADDED Requirements

### Requirement: 메시지 답장 작성
시스템은 참여자가 같은 채팅방의 텍스트 또는 이미지 메시지를 답장 대상으로 선택하고 전송 전에 대상 정보를 MUST 확인하거나 취소할 수 있게 해야 한다.

#### Scenario: 텍스트 메시지에 답장
- **WHEN** 참여자가 텍스트 메시지의 답장을 선택한다
- **THEN** 시스템은 입력창 위에 원문 작성자와 본문 일부 및 취소 동작을 표시한다

#### Scenario: 이미지 메시지에 답장
- **WHEN** 참여자가 이미지 메시지의 답장을 선택한다
- **THEN** 시스템은 입력창 위에 원문 작성자와 `사진` 표시 및 취소 동작을 표시한다

#### Scenario: 답장 취소
- **WHEN** 참여자가 작성 중인 답장의 취소를 선택한다
- **THEN** 시스템은 입력한 새 메시지 내용은 유지하고 답장 대상만 제거한다

### Requirement: 답장 참조 무결성
시스템은 답장 대상이 새 메시지와 같은 채팅방에 속하는지 MUST 검증하고 서버가 원문 인용 스냅샷을 확정해야 한다.

#### Scenario: 같은 방 메시지에 답장
- **WHEN** 참여자가 현재 방의 유효한 메시지 ID를 답장 대상으로 전송한다
- **THEN** 시스템은 원문 ID, 작성자명, 본문 일부와 메시지 유형을 새 메시지에 연결한다

#### Scenario: 다른 방 메시지 참조
- **WHEN** 참여자가 다른 채팅방 메시지 ID를 답장 대상으로 제출한다
- **THEN** 데이터베이스는 메시지 저장을 거부한다

#### Scenario: 인용 내용 위조
- **WHEN** 클라이언트가 원문과 다른 작성자명이나 본문 스냅샷을 제출한다
- **THEN** 시스템은 클라이언트 값을 신뢰하지 않고 서버에서 조회한 원문 정보만 저장한다

### Requirement: 답장 인용 표시와 원문 이동
시스템은 답장 말풍선에 인용 내용을 MUST 표시하고 조회 가능한 원문으로 이동할 수 있게 해야 한다.

#### Scenario: 로드된 원문 선택
- **WHEN** 사용자가 현재 목록에 로드된 답장 인용 영역을 선택한다
- **THEN** 시스템은 원문 위젯이 현재 화면 밖에서 폐기된 상태여도 메시지 인덱스로 위치를 복원해 해당 원문이 보이는 위치로 스크롤한다

#### Scenario: 이전 페이지의 원문 선택
- **WHEN** 사용자가 현재 목록에 없는 조회 가능한 원문의 인용 영역을 선택한다
- **THEN** 시스템은 원문 주변 내역을 조회하고 해당 메시지가 보이는 위치로 이동한다

#### Scenario: 원문을 조회할 수 없음
- **WHEN** 원문이 삭제되었거나 참여자가 더 이상 조회할 수 없다
- **THEN** 시스템은 저장된 인용 내용을 유지하고 원문 이동이 불가능함을 표시한다

#### Scenario: 답장 전송 재시도
- **WHEN** 답장 메시지의 최초 전송이 실패하고 사용자가 재시도한다
- **THEN** 시스템은 동일한 답장 대상과 인용 표시를 유지하며 메시지를 중복 생성하지 않는다

### Requirement: 텍스트 메시지 복사
시스템은 텍스트 메시지의 전체 또는 선택한 일부를 클립보드로 복사할 수 있게 하며 기존 답장 동작을 MUST 유지해야 한다.

#### Scenario: 텍스트 메시지를 길게 누름
- **WHEN** 사용자가 텍스트 메시지를 길게 누른다
- **THEN** 시스템은 `전체 복사`, `부분 복사`, `답장` 선택창을 표시한다

#### Scenario: 전체 복사
- **WHEN** 사용자가 `전체 복사`를 선택한다
- **THEN** 시스템은 메시지 전체를 클립보드에 저장하고 완료 안내를 표시한다

#### Scenario: 부분 복사
- **WHEN** 사용자가 `부분 복사`를 선택한다
- **THEN** 시스템은 메시지 내용을 선택할 수 있는 별도 창을 표시한다
