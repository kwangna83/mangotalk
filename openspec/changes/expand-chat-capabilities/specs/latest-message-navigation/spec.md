## ADDED Requirements

### Requirement: 최신 메시지 이동 버튼
시스템은 사용자가 최신 메시지 근처에서 벗어난 경우 최신 위치로 이동하는 플로팅 버튼을 MUST 제공해야 한다.

#### Scenario: 이전 대화 탐색
- **WHEN** 사용자가 위로 스크롤해 최신 메시지 근처에서 벗어난다
- **THEN** 시스템은 입력창 위 우측에 아래쪽 화살표 플로팅 버튼을 표시한다

#### Scenario: 최신 메시지로 이동
- **WHEN** 사용자가 최신 메시지 이동 버튼을 선택한다
- **THEN** 시스템은 마지막 메시지가 보이는 위치로 부드럽게 스크롤하고 버튼을 숨긴다

#### Scenario: 최신 위치에 있음
- **WHEN** 마지막 메시지가 보이는 최신 위치에 있거나 메시지가 없다
- **THEN** 시스템은 최신 메시지 이동 버튼을 표시하지 않는다

#### Scenario: 새 메시지 개수 제외
- **WHEN** 최신 메시지 이동 버튼이 표시된다
- **THEN** 시스템은 버튼에 새 메시지 개수나 숫자 배지를 표시하지 않는다

### Requirement: 입력 UI와의 배치 안정성
시스템은 최신 메시지 이동 버튼이 키보드와 메시지 입력 UI를 가리지 않도록 MUST 배치해야 한다.

#### Scenario: 키보드 또는 입력창 높이 변경
- **WHEN** 키보드가 열리거나 답장 미리보기로 입력 영역 높이가 변경된다
- **THEN** 시스템은 버튼을 입력 영역 위에 유지한다

#### Scenario: 원문 이동 후 복귀
- **WHEN** 사용자가 답장 인용 영역을 선택해 이전 원문으로 이동한다
- **THEN** 시스템은 최신 메시지 이동 버튼을 표시하여 마지막 메시지로 복귀할 수 있게 한다
