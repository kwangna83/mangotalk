## 3. 이미지 해석과 표시

- [x] 3.1 캐시 hit을 우선 반환하고 miss에서만 signed URL을 다운로드·검증·저장하는 이미지 resolver를 구현한다
- [x] 3.2 동일 캐시 키의 진행 중 요청을 합치고 빈 응답·MIME 불일치·decode 실패 항목을 저장하지 않는 테스트를 작성한다
- [x] 3.3 손상되거나 퇴거된 캐시 항목을 삭제하고 네트워크로 한 번 복구하는 흐름을 구현한다
- [x] 3.4 Web 캐시 바이트의 Blob URL을 생성하고 위젯 dispose 시 revoke하며 실패 시 `Image.network`로 전환한다
- [x] 3.5 저장된 width/height 또는 로컬 측정값으로 고정 종횡비 placeholder와 최종 이미지 영역을 렌더링한다
- [x] 3.6 크기 메타데이터 유무와 로딩 완료 전후에 메시지 높이가 안정적인지 위젯 테스트를 작성한다
- [x] 3.7 캐시 확인 전 signed URL을 발급하지 않고 서로 다른 다운로드·검증을 최대 4개로 제한한다
- [x] 3.8 목록 이미지는 표시 크기에 맞춰 축소 디코딩하고 codec·Blob URL 생명주기 및 동시성 테스트를 작성한다
